# Guide — Comptage de caisse

## 1. Ouvrir l'application

Ouvrez l'adresse que le gérant vous a donnée, dans le navigateur de la tablette ou de l'ordinateur de caisse (Chrome, Edge ou Safari).

## 2. L'installer sur l'appareil

L'installation permet d'ouvrir l'application comme une appli, même sans connexion.

- **Chrome ou Edge** : appuyez sur « Installer l'application », sur la page d'accueil.
- **Safari (iPad, iPhone)** : bouton Partager, puis « Sur l'écran d'accueil ».
- **Safari (Mac)** : menu Fichier, puis « Ajouter au Dock ».

## 3. Premier lancement

Sur un appareil neuf, l'application propose deux choix :

- **Reprendre l'historique du restaurant** : choisissez le fichier de sauvegarde remis par le gérant. Son nom commence par `sauvegarde_caisse`.
- **Démarrer une nouvelle caisse** : l'application démarre vide. Le premier comptage fixe le fond de caisse de départ.

## 4. Compter la caisse en fin de service

1. Sur l'accueil, appuyez sur « Commencer le comptage ».
2. Saisissez le total des pièces, puis le nombre de billets de chaque valeur.
3. Ajoutez les titres-restaurant et les chèques vacances, un par un.
4. Notez les mouvements de la journée : achats payés avec la caisse, remboursements, recharge.
5. Recopiez le montant « espèces » de SumUp.
6. Dans la synthèse, vérifiez l'écart, préparez la pochette avec les billets indiqués, écrivez votre prénom, puis appuyez sur « Clôturer le comptage ».

Chaque saisie est enregistrée tout de suite : fermer l'application ne fait rien perdre.

Si l'écart dépasse la tolérance, un commentaire est demandé avant la clôture.

## 5. Un jour n'a pas été compté

L'accueil le signale. Trois possibilités :

- le restaurant était fermé : « Marquer ce jour comme fermé » ;
- le restaurant était ouvert : « Faire un comptage cumulé », puis saisissez le montant SumUp de chaque jour ;
- la coupure est trop longue pour s'y retrouver : « Réinitialiser le fond de caisse ».

## 6. Sauvegarder

Les comptages sont enregistrés **uniquement sur cet appareil**. Ils ne sont pas envoyés ailleurs.

Une fois par semaine, l'accueil rappelle de télécharger une sauvegarde. Envoyez ce fichier au gérant ou rangez-le dans un endroit sûr.

## 7. Changer d'appareil

1. Sur l'ancien appareil : Réglages → « Télécharger une sauvegarde ».
2. Transférez le fichier sur le nouvel appareil.
3. Sur le nouvel appareil : ouvrez l'application et choisissez « Reprendre l'historique du restaurant ».

Ensuite, n'utilisez plus qu'un seul appareil : deux appareils ne se mettent pas à jour l'un l'autre.
